# 食用方法

只阅读**ALSA框架.md**即可，其他三个文件夹和插图有关，无需关注。

理想情况下是搭配着某国产桌面操作系统食用，但是商业项目不开源，所以建议去Linux上游拉取一份内核源码 https://www.kernel.org ，版本 4.19.90、6.6 两者应该都行，**搭配着 Linux 源码进行框架学习**。

或许你在阅读时很吃力很抽象，那是 no problem 的，哪里不懂了就问 AI ，只是进行框架学习，而不是进行“深度学习”，因为一个在校生/本科生确实无法掌握整个子系统的内容，掌握框架即可。

**（我本身也不确定你能否通过这份资料学习，不过别抱有很多期待，因为这份资料本质上只是告诉你很多关键字，你只是需要了解这些关键字的作用和位置）**
